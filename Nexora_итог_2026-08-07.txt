== ВАЖНО: вставьте ключи на Vercel ==

Сейчас реальные платежи и VK-вход выключены — на Vercel не заданы ключи.
Зайди на https://vercel.com → проект nexora → Settings → Environment
Variables и добавь (для Production):

  FRIDE_MERCHANT_ID   = твой ID мерчанта во Fride
  FRIDE_API_KEY       = секрет мерчанта во Fride (им же подписывается webhook)
  VK_CLIENT_ID        = ID приложения VK
  VK_CLIENT_SECRET    = защищённый ключ приложения VK
  (необязательно)
  TELEGRAM_BOT_TOKEN  = токен бота для уведомлений об оплате.
                        Если не задавать — используется бот Nexora1s_bot.

После добавления — передеплой:  cd "Nexora новый" && vercel --prod --yes

Без FRIDE_* сайт работает в тестовом режиме оплаты (пометка в интерфейсе).
Без VK_* кнопка «VK» вернёт понятную ошибку.
